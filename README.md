# Asteroids: A simple Python game

Asteroids is a simple project to learn object oriented programming while learning to write code from scratch.

## Getting started

To install and try out Asteroids follow these steps:

### Prerequisites

* Python 3.10+
* UV project/package manager
 
1. Create a new uv project:
```bash
uv init --no-package --python 3.13 your-project-name
cd your-project-name
```

2. Create a virtual enviroment at the top of your project directory:
```bash
uv venv
```

3. Activate the virtual enviroment:
```bash
source .venv/bin/activate
```

4. Add pygame library as a project dependancy:
```bash
uv add pygame==2.6.1
```

5. Clone the repository to your project directory:
```bash
git clone [https://github.com/AurimasPankunas/Asteroids.git](https://github.com/AurimasPankunas/Asteroids.git)
```
